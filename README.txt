Сайт доставки в сервисные центры

Файлы index.html, style.css и script.js должны лежать в одной папке.
Для проверки откройте index.html в браузере.
Для GitHub Pages загрузите все три файла в корень репозитория и включите Settings → Pages → Deploy from a branch → main → / (root).

Заявки сохраняются в браузере на одном устройстве. Для определения адресов нужен интернет. Порядок точек приблизительный, по расстоянию по прямой; перед выездом проверьте маршрут в навигаторе. Excel открывает выгружаемый CSV.
